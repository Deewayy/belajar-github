# Belajar GitHub

Project sederhana untuk mempelajari dasar Git dan GitHub.

## 📌 Tentang Project

Project ini dibuat sebagai latihan untuk memahami workflow Git dan GitHub, mulai dari membuat repository, melakukan commit, membuat branch, hingga menyelesaikan merge conflict.

## 🛠️ Teknologi

* HTML
* Git
* GitHub

## 📂 Struktur Project

```text
BELAJAR_GIT/
├── index.html
├── README.md
└── .gitignore
```

## 🚀 Cara Menjalankan

1. Clone repository:

   ```bash
   git clone URL_REPOSITORY
   ```

2. Masuk ke folder project:

   ```bash
   cd BELAJAR_GIT
   ```

3. Buka `index.html` menggunakan browser.
